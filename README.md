# MiBolsillo

Aplicación móvil Android para el registro y control de gastos personales. Proyecto del módulo Herramientas de Programación Móvil I — Politécnico Grancolombiano.

Entrega 1: estructura de la aplicación con dos fragmentos y la interfaz de las cinco pantallas. La lógica financiera se implemento en la Entrega 2. y se realiza la Entrega 3 con la terminación de la aplicación.

Java · minSdk 24 · Android Studio
